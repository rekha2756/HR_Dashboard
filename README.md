# PeopleDesk — Employee Management System

A responsive employee management dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Dashboard with employee, attendance, leave and department summaries
- Employee CRUD: add, view, edit and delete
- Search employees and filter by department/status
- Daily attendance: Present, Absent and Leave; mark all present
- Leave request review: approve or reject sample requests
- Responsive layout for desktop and mobile
- Local persistence using browser localStorage

## Run
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser.
3. No build tools or installation are required.

## Important
This is a frontend-only demo. Data is saved in the current browser using localStorage.
There is no server, database, real authentication, employee self-service login, or multi-user
synchronization. The sample leave requests and employee records are demo data. For production,
connect the interface to a secure backend and database, add authentication/authorization,
server-side validation, audit logs and backups.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — application logic and localStorage
